## Quick start

```bash
# 1. Download the global template catalog
slopctl templates --update

# 2. Initialize your project
cd your-project
slopctl init --lang rust --agent claude
```

That single `init` call copies the main `AGENTS.md` template, merges in skill-hint fragments,
installs language config files, and sets up Agent Skills under `.agents/skills/` — ready for
every supported agent, not just the one you named.
